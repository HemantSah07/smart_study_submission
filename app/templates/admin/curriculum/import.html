Ingestion Safety & Architecture

1. Extraction
Multi-Format Parser
Extracts text, headings, and tables from DOCX, PDF (PyMuPDF), and PPTX without database side-effects.
2. Deduplication
Global Subject Matcher
Calculates match confidence scores (0.0-1.0) against existing global subject codes and names.
3. Admin Review
Interactive Preview
Allows admin to set LINK_EXISTING, CREATE_NEW, or SKIP action on each extracted subject row.
4. Atomic Commit
Transactional Ingestion
Writes mappings into ProgramSubject table atomically with full rollback if an error occurs.
